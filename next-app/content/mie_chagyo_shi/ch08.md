# 第八章　茶業研究

## 試験研究組織の変遷

### (1) 三重県茶業組合聯合会議所「茶業試験所」設立（明治42年：1909）

　本県における茶業研究は明治42年（1909）に三重県茶業組合聯合会議所が設立した「茶業試験所」に始まる。当時の茶業情勢は粗製濫造の悪弊を除去せんとする不正茶の流行で、海外での日本茶の評価は著しく低下していた。政府は明治27年（1894）製茶改良事業を起こし、日本茶の品質改良を図ったが一向に成果を見ず。ここから、茶業組合中央会議所に補助金を交付して茶産地府県に茶業試験所の設置を進めた。

　三重県茶業組合聯合会議所は明治42年（1909）、茶業組合中央会議所から360円の補助金を受け、津市下部田に茶業試験所を設置し、緑茶及び紅茶の製茶の研究に着手すると共に、試験所内に製茶伝習所を開設し、茶業技術者の養成を図った。

（註）設立当初の茶業試験所の概要は次のとおりであった。<br>

　・建物面積　土地1反9畝15歩（借地）<br>
　・建物279坪<br>
　　　内訳　事務室22.5坪、製茶研究室74.0坪、生葉時試験室8.0坪、製茶調整苗育蔵室30.0坪、<br>

### (2) 三重県茶業組合会議所「茶業試験所」を三重県に移管
<div style="margin: 0;text-align: right";>（大正15年：1926）</div>

　明治42年（1909）、本県最初の茶業試験研究機関として誕生した三重県茶業組合会議所「茶業試験所」は大正10年（1921）頃からの日本経済の不況で茶況が悪化し、その運営が困難になったことから三重県に移管され、 三重県茶業試験所として建物施設、試験圃場をそのまま引き継ぎ、県による茶業試験研究が開始された。

　当時の職員として、技師 国持武雄、 投手 (地方技師) 谷本仁助、 投手 小山寅蔵、属 西岡市太郎の名前がある。

### (3) 三重県茶業試験所を鈴鹿郡亀山町亀田に移転(昭和12年: 1937)

　大正15年(1926) 県移管された県茶業試験所は津市下部田周辺では試験圃場が狭隘で充分な試験が困難なことから、 昭和12年(1937) 鈴鹿郡亀山町亀田字甲411番地 (現亀山市亀田、 亀山市総合医療センターの場所)に移転した。

(註1) 移転した当時の三重県茶業試験所の施設の概要は次のとおり。<br>
　(1) 土地及び建物<br>
　・土地総面積3町5反5畝9歩<br>
　　内訳: 圃場 2町5反9歩、 建物敷地4反9畝、 道路其他4反8畝<br>
　・建物総坪数395,8坪、<br>
　　内訳: 事務所49坪、 研究室196坪、 雑屋151坪<br>
　(2)職制(昭和12年3月31日 三重県訓令甲第16号)
<div style="margin: 0; text-align: center;">三重県茶業試験所職制及び業務規程</div>
　第1条 茶業試験所は茶業に関する次の業務を行なう。<br>
　　1. 試験研究及び調査<br>
　　2. 講習・講話及び実施指導<br>
　　3. 種苗及び製茶見本の配布<br>
　　4. 技術者の養成<br>
　　5. 其他必要な事業<br>
　第2条 茶業試験所に次の職員を置く。<br>
　　所長<br>
　　地方農林技師 (昭和17年11月地方技師と改正)<br>
　　農林 主事補(　全　属と改正)<br>
　　農林技手( 全　属と改正)<br>
　　　所長は地方農林技師を以て之に充<br>
　第3条 (以下省略)<br>
　　付則 本規程は昭和12年4月よりこれを施行する。<br>
(註2) 当時の職員として、 所長 国持武雄、地方技師 谷本仁助、 投手 土屋孝一、技手 加藤明昌、 属 近澤僑二の名前がある。<br>
(註3) 県茶業試験所の移転用地について、 亀山町が3町55畝を提供することにしていた用地の無償提供については、将来何かと支障を来たすことも予想されることから県が坪125円で買入れた。<br>
(註4)建設・施設資金は亀山市6,500円、 三重県茶業組合聯合会議所3,500円の寄付金と県費17,000円、 計27,000円を以って、 昭和10年(1935) 着工、 同12年(1937)3月に移転が完了し、 同4月から新機構の下に試験研究が開始された。

### (4) 昭和25年(1950)三重県茶業試験所は三重県農業試験場茶業分場と改組

　県の試験研究機関の統合により、三重県茶業試験所は三重県農業試験場に統合され、 三重県農業試験場茶業分場となった。

(註) 建物施設、 試験圃場等は昭和12年(1937)と変わらず、当時の職員は村瀬康作分場長以下11名の陣容であった。

### (5)昭和29年(1953)、 多気郡川添村栃原に三重県南勢茶指導所設置

　南勢地域の茶業指導の拠点として、 多気郡川添村(現多気郡大台町栃原)に南勢茶指導所が設立され、 南勢茶の指導に当ったが、 昭和37年 (1962) 4月、 県の機改革により試験研究機関に編入され、 三重県農業試験場茶業分場南勢茶試験地と名称を変更し、 南勢地域の茶試験研究を担当する機関となった。

(註) 設立当時の南勢茶指導所の建物施設は次の通り。 (現在も建物等の改築がされたものの当時と変わらず。)
　・建物施設181坪　・試験圃場 5反歩

### (6) 昭和45年(1970) 三重県農業試験場茶業分場は、 三重県農業技術センター茶業センターに名称変更

　県の機構改革により、 三重県農業試験場茶業分場は三重県農業技術センター茶業センターに名称変更された。

### (7)昭和60年(1985) 三重県農業技術センター茶業センターは亀山市椿世町992-2に移転

　三重県農業技術センター茶業センターは亀山市亀田町付近が宅地開発され、 茶業研究に支障を来すことから、 亀山市椿世町992-2番地 (現在地) に移転し、 新しく試験研究業務を開始した。

(註) 移転した茶業センターは次のとおり。<br>
　① 建物施設<br>
　　・総面積 45,484㎡ (内 建物敷地9,131㎡、 試験圃場19,000㎡)<br>
　　・建物 本館及び研修室791㎡、 荒茶加工施設481㎡、 再製加工施設112㎡、<br>
　　　機械格納庫154㎡、 収納舎84㎡、 堆肥舎80㎡、 ガラス室36㎡)<br>
　②職員庄山孝義場長以下、 職員11名<br>

### (8) 平成14年(2002) 三重県農業技術センター茶業センターは三重県科学技術振興センター農業研究部茶業研究室に、更に平成20年(2008) 三重県農業研究所茶業研究室に名称変更

　平成14年(2002) 県の試験研究機関統合により、 農業、 水産、 工業、窯業の各試験研究機関を統括する三重県科学技術振興センターが四日市桜町に設置され、茶業センターは茶業研究室として、 同農業研究部の一部署と位置付けられた。

## 4．明治42年（1909）〜大正14年（1925）に至る試験研究の概要

　明治42年（1909）三重県茶業組合聯合会議所茶業試験所設立以降、大正15年（1926）の県移管までの資料が離散し明らかではないが、当時は輸出茶の粗製濫造や不正茶（着色茶等）が横行し、米国から着色茶輸入禁止措置が取られるなど、日本茶の評価は低下し茶価が低迷していたことから、政府は製茶改良事業を以って茶生産府県に茶業試験所を設置し製茶改良を進めた経緯があり、明治42年（1909）に設置された三重県茶業組合聯合会議所茶業試験所も当面の課題である製茶改良に試験研究の主力が注がれ、特に緑茶では共同蒸事業を起こし、鶺鴒（セキレイ）釜の普及に努めるとともに、各郡茶業組合に模範茶園を設置し、栽培の指導を行なった。

　一方、緑茶の輸出停滞から紅茶の生産奨励が行なわれ、茶業試験所でも紅茶試験を盛んに行なった。

　以下、三重県茶業組合聯合会議所茶業試験所の設立当初（明治42年 1909）から大正10年（1921）頃迄に至る主要試験研究事項は次のとおり。

<strong>（1）各種試験</strong><br>
　三重県の茶業（大正9年 1920発行）には「明治43年（1908）津市下部田に茶業試験所を新築移転せり、構内には紅緑茶試験工場、整理工場、機械工場、紅茶萎室等合計四棟を有し、亦別に試験茶園二町歩を経営し、栽培種類試験、肥料試験、病虫害防除試験等を行ふ」と記述されている。

<strong>（2）模範茶園の設置と指導</strong><br>
　明治44年（1911）の茶業試験所の業務の中で、県茶業組合聯合会議所が各郡茶業組合単位に設置した模範茶園での農家への栽培指導に重きが置かれていたようである。

<strong>（3）共同蒸事業</strong><br>
三重県茶業要覧（大正6年 1917発行）には共同蒸事業について次の記述がある。
<div style="margin: 0 0 0 2rem">
　「茶蒸器具の善悪及之れが使用方法の拙劣なるは作業上困難を来すのみならず其の蒸葉に及ぼす影響亦大にして、従って製茶品質の向上は得て望む可らず殊に蒸の不完全なるは貯蔵中に於て品質を失墜すること実に多大なりとす、故に是等の弊害を刷掃し範を示さんため県に於て明治四十四年以来最も軽便なる自動茶蒸器を購入し村農会若くは茶業組合等の団体に貸与し、或は其の事業に補助し作業せしめたるには其成績頗る良好にして、従来の蒸器に比し経費僅かに半額若くは三分一にて足り使用者の如何を問わず一定の蒸上をなすを得、殊に本器は短時間に多額の生葉を蒸上ぐるを以て小生産家の部落にしては一台を以て数十戸の共同蒸をなすを得、販売上最も困難なる色沢の統一は比較的容易なるに至り、」
</div>

　以上の記述の様に、本県は製茶品質向上には生葉の蒸工程の改善が重要として、県を挙げて共同蒸事業を展開し、 特に製茶の色沢の向上と統一に好成績を納めたが、この成績取り纏めに茶業試験所は重要な役割を果した。

　一方、共同蒸事業には鶴鶴(セキレイ) 釜を使用したが、 「大正5年三重県茶業要覧」には鶺鴒釜について、 次の記述がある。
<div style="margin: 0 0 0 2rem">
「茶葉蒸の巧拙に依りて製茶に及ぼす影響に関しては、 近時著しく需要者間に宣伝せられ、これが結果として蒸装置の不完全は作業の進歩上不得策のみならず、其蒸葉に必ず悪結果を来し、 製茶上の欠点として常に認めらるゝは香味水色に悪影響を来すは勿論、貯蔵後に於て品質を失墜するこたは実に生産家の想像外なりとす、 故にこれが弊習を刷掃せんと浴し、 現今最も進歩したる鶴鴒釜利用の蒸装置を為したるものには茶業組合聯合会議所より相当の補助を為し、 明治四十一年以来、県下に之れを奨励したるに…(中略)…好成績を示すに至れり、｣
</div>

## 5．大正15年（1926）〜昭和30年（1955）に至る試験研究の概要
<div style="text-align: right;">（三重県農業試験場史より）</div>

### （1）育種に関する試験
　本県の茶品種改良に関する試験は昭和7年（1932）からである。太平洋戦争真近い昭和16年（1941）頃間までは、主に茶樹の蒐集維持保存、これらの増殖、候補原樹の性能調査、茶樹品種及び優良品種の性能に関する試験等の準備が進められ、昭和14年（1939）頃から繁殖方法として取木法及び挿木法に関する試験も同時に進められた。

　戦後は戦前調査の足らない事項或いは再検討に費やしたが、その主なものを挙げると、①品種間の挿木時期試験、②優良品種比較試験、③茶樹品種のビタミンCの調査、④茶樹の種子に関する研究等が行われた。又各府県で選抜された有望系統、紅茶系統10、緑茶系統9について、本県に於ける適否試験が昭和13年（1938）から着手された。これは全国共通試験として行われたものである。

　その他、分離育種及び交雑育種が行われ、育種の基礎的研究として茶樹の倍数体の研究と挿木苗の花蕾の着生と生育に関する影響が取り上げられている。
挿木育苗法として、挿し穂に対する被覆処理による発根促進に関する研究が昭和26年（1951）度から28年（1952）度迄続けられたが、29年（1954）度に至って黄化処理による発根促進と同様な事が証明され、引き続いて研究を進めた結果、この黄化処理は挿木の発根に効果のあることを確かめ得た。

　従来、茶樹の育苗は手数と期間とを多く要するものであったが、挿木を本畑へ直か挿しする方法が研究実証されたことから茶園造成は1年短縮が可能となり、活着後の生育も良好であることが判明された。その他発根促進剤の使用法についても種々試験が行われている。

　総体的に見て茶は年々供給増加の傾向にあることから、この儘で進むならば近い内に供給過剰も無いとは限らない。 この様な情勢に対処するため研究指導機関では、先ず茶園の品種、 茶園の造成に意を注ぎ、 優良茶園の増殖に努めた。

　茶の品種育成 改良は極めて長い年月を要し、 苗の繁殖亦容易ではなく、 多少でも生産をあげるようになる迄は少なくとも4~5年を要し、その上適性検定を経なければ登録品種とする事は出来ない規制がある。 そればかりではなく茶は他の作物に比べて遅育性な事から急速な要請には応じ難い条件下にある。

　又緑茶園と紅茶園とは原葉に対する性格上の要求が違う事などの複雑さがあるから、例え緑茶用として優良な品種であっても、それを以て紅茶の優良品は製造し得られないとされている。

　現在我が国で登録されている品種は次のとおりであるが、 茶の品種は地方に於ける適応性、地域性による茶業経営の方針等によって選択されることから、これ等の点から試験場は、それらの適否試験の成績よりして、緑茶品種として、 やぶきたやまとみどり、まきのはらわせ、 あさつゆ、 たまみどり等、 紅茶用品種として、ベにほまれ、 はつもみじ等が奨励品種とされている。

### (2) 栽培に関する試験研究事項

　記録の明確なものとしては、大正15年 (1926) を初年として昭和9年(1934)で連続して、先づ肥料種類試験、窒素の要量、 茶樹の整枝時期、 仕立、剪定法及び茶樹の病害予防等所謂栽培上の基礎的な課題と取り組み、次いで昭和5年(1930)からは別に一定地区で同一耕種法による茶樹の所定期日に於ける作柄を纏めて記録し、例年と比較対照し更に気象を参酌して、 その年の作柄を県下に周知せしめる作柄調査報告等を開始して当業者への羅針盤の役割を果しめようとした。

　翌昭和7年(1932)から茶園の霜害予防、品質向上と茶園被覆の問題、老衰園の更新、茶種子播種と基肥用量、同基肥時期、或は茶樹の移植時期、 同方法等の摘技術的にからめて至難と見られる課題を中心としている。以上の様な研究課題が相前後して、 或は繰り返し検討されながら昭和15 (1940)年頃に及んで、 夜間被覆試験、 台刈位置の高低、 鋏摘茶園の仕立法等の試験が試みられ、この時代から茶園造成上に大きな変革がもたらされるのではないかという様な事象の窺かがわれ出しているとも云われるに至った。

　この仕立法に続いて、 茶葉摘採法に関係ある試験中、 特に手摘と鋏摘能率比較、茶摘鋏刃渡り長さと能率の関係及びその袋の大小、鋏の操作方式、次いで鋏摘茶園の標準摘採法設定試験、 言い換えれば将来の製茶法はこの摘採法にすべては依存するに至るだろうと予想されそうな傾向さえ窺えるようになった。

　あたかも支那事変 (日中戦争) に端を発した太平洋戦争突入により農地作付統制は容赦なく、 茶、桑園、 果樹園は不急作物とし主食糧増産の犠牲に追いやった。 あの時代に前記の試験研究課題に取り込まなければならなかった事は、 必ずしも過去の事ではなかったであろう。

　越えて、 戦後昭和21年 (1946)~22年(1947) に至っては、 早くも輸出用緑茶栽培、品種薮北に関する生理学的な検討、 茶園間作との関係から茶園の樹型と畝間の問題等、 経営管理に関係の密接な課題を対照としていた事に注目しなければならない。

　更に数歩進めて、茶樹の本畑直挿に関する予備試験、 その床土比較、 日覆方式及び挿木試験等に分かれて行われている。 試験場が挿木繁殖の試験を取り上げたのは、その外昭和27年(1952) ~29年 (1954) に亘る繁殖関係試験、品種間の挿木時期の検討等貴重なものである。

　然も最近になって、植物ホルモンの応用によるこの種の試験は、その効果を除いてめざましいものがある。

　この画期的な実験を然も短期間に見事に成就せしめた本県茶業研究の功績は偉大というもおろか永久に茶業史上に記しておかなければならない実績であろう。

　これらの実験結果に加えて更にその効果を一層発揮せしめえる付帯研究として、茶の直挿し、 施肥法の問題、 挿木の着葉数と発根との関係、挿木床のクリリウムの使用可否とその効果、 農業用塩化ビニール被覆効果、 茶の播種又は移植溝の深浅度の検討等を骨子とした試験が数多く行われている。 それは丁度昭和26年(1951)頃から30年(1955) 頃に亘っている

　栽培に関する試験の中、 特に付け加えておきたい試験業績があるが、それは試験所が亀山に移転した時 (昭和12年 1937) から行われた茶樹栽植密度試験がある。即ち永年作物である茶園は栽植距離とか播種量とかは後年の於ける生産力に大きく響く、又茶園造成上の基本問題である所から、 先ず間引距離試験や播種量試験を手始めに、更に昭和14年(1939) からは茶苗栽植密度試験に移り、これらの試験結果は収量と栽植密度を明らかにし、以後の茶園造成の指針として大きな業績となった。

### (3) 製茶に関する試験研究事項

　手揉法に始まった本県の製茶の歴史は真に長いのであるが、 研究の上にも研究を重ねた結果、製品の色沢、 香味を保たせる技術的な特色は長い間の積み重ねによって培われたものであって充分讃美されるものであるが、然し又、その量的生産、生産費等の問題、又は生産能率の高い合理的な方法に切り替える事も客観状勢からして当然考えるべき問題であった。

　製茶に関する試験課題について年次を追ってみると、 近年でこそ殆んど全工程が機械化に切り替えられているが、 そこに至る迄の間には幾多の困難と闘いつづけた事を認めない訳にはいかないのである。

　機械製茶については、当業者間にも直接取り組んだ幾多の尊い工夫、構想はあったにしても、それは部分的なものゝ 考案が試作品であったが、種々大がゝな程度に、然も例えそれは連鎖的操作法ではなくとも全工程の機械化が考えられ出したのは大正7年(1918)~8年(1919) の事であった。

　茶業試験所は機械に関する研究を具体的に始めたのは昭和2年(1927) からで、主として、 それは茶葉蒸機に関する研究であって、 粗揉機、 揉捻機、 精揉機に関する研究を実施すると同時に機械製茶対手揉製茶に関する研究に取り組んでいる。 勿論、当時は試験所と雖もその部分的な研究の累積と更に簡易な方式による機械製茶法の実験との結び付きに数次の研究改善が加わって斬新的状態であったのがその過程であった。

　越えて昭和5年(1930)、 県下の製茶生産額約60万貫に達し、且つその80%余は機械製茶が占めるという情勢になったので、試験所は従来の試験成績を綜合して「機械製茶法」 と題して茶業試験所業務報告の巻末に、蒸熱、 粗揉、 揉捻、 再乾、精揉、 乾燥及び一般注意事項の7項目に亘って詳細な解説を加えている。

### (4) 鋏摘法、機械製茶法の普及に対応した新たな研究課題

　昭和初期に至って鋏摘法、 機械製茶法の普及が進み、 茶業試験所もこれに対応する新たな試験課題への取組みが行われた。 例を上げれば次のものがある。

ア、 製茶用ボイラーの研究と設置普及奨励<br>
　この試験に取り組んだのは大正15年 (1926) 試験所県移管間もなくで、県下関町秋葉鉄工所設計試作になる横置多管式小型ボイラーを採用することを決め、従来の「セキレイ釜」に比べて効率高く製品優良である事の実証を得たので、丈に若干の工夫改善を加えたボイラーを試作し、昭和4年(1929)試験所内に取付け実験を試みた所、成績極めて優秀と判断し得たので、 県当局及び県茶業聯合会議所は当該ボイラー設置替使用するものには助成金を交付する措置を取った。この結果、昭和5年(1930) の県内普及率は僅かに7%程のものが、昭和15年(1940)には73%と10年間で10倍の増加を示すに至った。<br>
　然し、その後戦時資材類の統制強化で制作は殆ど中止の状態に陥ったが、このボイラー使用によって燃料費の節約と製茶品質向上等に対して優れた性能成果を現した事は今なお定評のある所である。

イ、地下集中煙突の研究と設置の普及<br>
　工場地帯に於ける煤煙問題が物議をかもし、 製茶工場も亦同様の問題の発生が懸念されている。<br>
　当時、 静岡県で地下集中煙突が広く使用されている事を知り、該地につき調査の結果、急いでこれを採用する事を決め、 昭和4年(1929) 施工にかかり経験を積み重ね又幾多の検討改善を加え、 漸く快調優秀な成績である事を確かめ得たので、昭和5年(1930) これを三重郡小山田村松野工場に設置せしめる事を奨めて、テストケースとした所、 全県下の業者から申込み急速の増え、 殆ど100%の普及率を示したという事である。

ウ、 炒蒸機の改良試作試験<br>
　高性能な玉緑茶用炒蒸機試作のため農林省応用研究費によって、 この試験が昭和26年(1951)~27年(1952) に亘って実施された。 三段から成る連続妙葉機を完成した。 本県は蒸能率時間当たり112.5kgで茶葉の重量減33%、 茶葉通過時間3~4分、 燃料消費量は松薪1時間当たり15kgで足り、 製茶品質は湯蒸しに比し色沢帯黄、渋味がなく釜炒茶に似た風味の製品を得たので、 輸出向玉緑茶用機械として大いに注目されるに至った。

エ、高能率鋏摘法の研究と普及<br>
　鋏摘に関する試験は重要な課題として累年に亘って研究に就いていたが、昭和12年(1937)の所謂支那事変(日中戦争) 前後から農村労働力の不足と茶摘労賃の高騰で茶摘作業の省力能率化は緊急の課題となっていた。 昭和14年(1939)頃から高効率鋏摘法の組織的技術の研究に着手し、各摘採期を通して鋏の様式、 袋の型式、 袋の移動方法、 鋏の大小軽量等基本的な試験を始め、 高効率標準鋏摘方式の創定に全力を傾け、 昭和15年には、 摘芽品質、摘跡適整、摘採能率の高い「標準鋏摘法方式」なるものを設定して、これが普及指導に各方面の協力を求めた所、各産地共積極的に取り入れ急速に普及をみた。

オ、鋏摘茶園に於ける改良仕立法の研究と普及<br>
　昭和12(1937)年茶業試験所移転に伴い、新移転地 (亀山町亀田)の茶園造成着手と同時に新構想を以てこれにあたり、 全園の永続的多収穫と摘採能率及び摘芽質の高度向上を目的とした合理的仕立法について研究する事になったが、その根底をなす諸要因を次の数項におき、そこから新しい着想を引き出そうと試みたのであった。即ち① 従来の慣行仕立方式、 ②従来の奨励法による方式、 ③ 老衰園の台刈更新、 ④ 鋏摘茶園に適さない現茶園の仕立替、 ⑤ 新植茶園の仕立当初からの毎年の操作方法、 等々各業者からの考案、 調査、実験を基として、その樹型、 枝葉の分岐様式から 「改良仕立法」 称するうね畦型仕立法が生み出されたのである。<br>
　要するに、 製茶に関する全試験を通して上記の実例 (①~⑥) の実験及び補導を行いながら、 地方では世情の平安、 財界の好況から貿易の好転など、 良い条件次々と原因して内地向玉緑茶製造と同様、 輸出向玉緑茶の製造試験、或いは紅茶に関しても昭和の初め頃製品の研究が行われ、同時にその生産地帯に関する条件調査、醗酵に関する試験、 揉捻時間と品質、 紅茶と機械採の問題、 昭和16年(1941)頃からは、茶樹品種と紅茶品質の関係を対照として試験が続けられたが、戦時にあたって十分な試験が出来なかった。 然し昭和28年に至り俄かに紅茶への関心が高まり、 県も率先して紅茶生産を奨励指導した。

### (5) 病虫害及び其の他に関する試験

　茶樹の病害虫の中、 最も被害が大きく駆除困難とされている葉巻虫の発生調査や誘殺法、 成虫捕殺、 誘蛾灯による習性の観察は、 昭和16年(1941) より開始された。昭和24年(1949) 以降は各種農薬の出現によって茶樹栽培上の障害をどの程度に駆逐し得るかの研究が主として赤ダニを対象として行われている。

　その他の事項として、 尿素と液体アンモニアの問題を取り上げて置きたい。 昭和24年(1949) 試験場は尿素の葉面散布の効果についての研究に着手した。 尿素の葉面散布によって葉面吸収の結果、 茶葉収量増加を目標に濃度、 散布回数、 時期等について実験を行った結果、 茶葉収量増加には効果が現れ難いが、 葉面散布によって茶葉から窒素を吸収し茶葉の緑色を増す事で、 製茶品質向上に効果がある事を実証し得た事、特に2番茶の品質改善に効果の顕著な事が業者のか関心をひき漸次実行者が増加した。

　或いは液体アンモニアの使用法等の新しい試みが行われたが、これは機械化施用の上、流安区と比較して、 生葉の収量或いは製品の品質に及ぼす影響を試みようとしたものである。

　又昭和24年(1949) からは茶業経営に関する調査研究、 或いは生産費に関する調査研究を生葉生産費と生葉加工費等に分けて検討している。

　更に昭和25年(1950) から茶樹の耐寒の生理的な面からの研究として、その判定に冬季における茶葉の樹液と屈折率と耐寒性の強弱について研究が続けられた結果、耐寒性も弱い品種は屈折率も小さい事が明らかになった。

　以上、 本県茶業試験場で行った主なものについて、 各部門毎の年次を追うて回顧したのであるが、全試験課題に亘ったものではない。 なお全試験課題については、次の試験研究並に調査事項表を以下記しておく。

## 6. 昭和31年(1956) ~平成20年(2008)に至る試験研究の概要

### (1) 育種に関する試験研究

　育種の試験は、茶樹は永年作物で成園到達期間が8年~10年を要し、結果を見るには20年以上の期間を有する。

　戦前(太平洋戦争) から続けられてきた育種に関する試験研究の成果をみると、昭和8年(1933)~38年(1963) において継続された多田系印度雑種性能調査については、印度アッサム系雑種で紅茶系品種の原種として利用可能とし、 その保存に努めてきた。現在においても、 現地 (南牟婁郡御浜町尾呂志地区) に現存し、更に県農業研究所茶業研究室圃場 (亀山市)に移植保存されている。

　昭和11年(1936)~40年(1965)に亘って続けられた茶樹の蒐集については、緑茶系、紅茶系等を含め多数の茶樹を蒐集し貴重な遺伝子試料として、また品種育成に係る原種として茶業研究室圃場で保存している。

　昭和28年(1953) から着手した4倍体茶樹の育成は、相当の成果を挙げ、 その利用を期待されたが、 最終的に遺伝子の固定が困難と判明し品種登録は実現しなかった。

　昭和29年(1954)から始まった交雑育種には、一時中断の時期はあったものの500余個体の中から系統選抜試験、 地域適応試験を経て最終的に2個体に絞り込み、 平成6年(1994)その内の一個体を、 「みえ緑萌1号」として品種登録された。 これは本県初の茶品種誕生である。

　なお、品種育成事業については、 昭和29年(1954) から国の事業として体系化され、国立茶業試験場 (静岡県金谷、 鹿児島県枕崎) 及び埼玉、 静岡、 京都、 宮崎の各府県茶業試験場を原種育成場に指定し、 本県は、これらの原種の地方適応性検定農場となったことから、昭和40年(1965)以降は地方適応性検定試験を除いては、本県単独の育種試験研究には主力を置いていない。

### (2) 栽培に関する試験研究

・繁殖に係る試験研究<br>
　挿木繁殖は昭和14年(1939) から着手しているもの、 本格的な試験が始まったのは、戦後の昭和23年(1948) 頃からとみられる。 この頃において国立茶業試験場等では挿木繁殖技術の蓄積が進み、 実生繁殖との優劣比較がなされ、さらに昭和30年(1955)に有望品種として 「やぶきた」 が品種登録されると、 茶業者にも挿木繁殖に関心が高まり、本県の試験研究は「やぶきた」の増殖に合わせて挿木繁殖の試験に重点が置かれた。 挿木繁殖技術の確立と普及は、昭和30年(1955)代の本県茶園面積の増加と品種茶園化に大きな役割を果たしたと云える。

　また、挿木繁殖の普及に合わせて、苗木床、 発根、苗木の移植など技術の開発などが昭和30年 (1955) 頃から盛んに行われ、 早期成園化技術確立への礎となっている

・茶園の土壌肥料に係る試験研究<br>
　戦後の緊急食糧増産が背景にあって、 多くの化学肥料が出現し、 その茶園施用方法と肥効についての試験が、 昭和30年(1955) 頃から急増している。

　また、化学肥料の出現で施肥方法の試験も多岐に及び、この頃からヨーソ、ジベラ、カリ、尿素などの葉面散布試験が行われ、肥料と品質の関係が明らかにされ多肥栽培への傾向が顕著化してきている。

　昭和40年(1965) 代には、 良質茶生産の奨励から、 特に窒素系肥料の多施用の傾向が表われ、 北勢地方にあっては10a当たり窒素成分量200kgを超える極端な多肥栽培が行われ、 試験研究においても多肥と茶樹生理の関係、 施肥の限界等を試験し、 多肥栽培に対して警告を鳴らしていたが、 昭和50年(1975) 代に入ると、多肥栽培茶園に生理障害が表われ、 昭和56年 (1981) から生理障害茶園の阻害要因解析と回復にかかる研究に着手し、 生理障害回避のため茶樹冠下施肥法や緩効性肥料の施用などの施肥改善を行なうと共に、土壌環境基礎調査を継続的に実施し、 土壌改善と併せて施肥の合理化と灌水チューブによる施肥等、 新しい施肥法に関する各種試験が行われた。

　一方、平成6年 (1994) 頃から茶園施肥が地下水汚染や地球温暖化の原因となっているとの指摘から減肥料による茶樹栽培技術の確立は試験研究の重要課題となり、平成9年(1997) からの土壌肥料関係の試験研究は、 減肥技術の総合組立、硝酸態窒素の環境基準化に即した茶生産システムの構築、 少肥栽培と窒素溶脱防止技術による環境保全型生産システムの確立など環境問題にリンクして行なわれている。

・かぶせ茶に係る試験研究<br>
　昭和7年(1932) ~10年(1935)にかけて茶葉の被覆試験を行っているが、この試験は玉露栽培に係る試験であろう。 かぶせ茶生産のための簡易被覆(茶園直がけ)試験は昭和24年(1949)、29年(1954) に行っているが、 主にビニール等を利用した早出しを目的にしたもので、化学繊維 (カンレーシャ)の茶園直がけのかぶせ茶栽培の試験研究を本格的に行ったのは昭和48年(1973) からである。この頃、宇治茶用被覆茶の需要が旺盛で、 北勢地方 (主に四日市水沢地区)でかぶせ茶の栽培の普及をみた。

　これに対応してかぶせ茶栽培に対する試験研究が大きなテーマとなった。 かぶせ茶栽培の試験研究は昭和48年(1973)から55年(1980) まで集中的に行われ、昭和55年(1980)にはかぶせ茶生産技術体系が確立した。 また、 現地ではかぶせ茶栽培が急速に普及し、昭和55年(1980)には北勢地方を中心に県下のかぶせ茶栽培面積は1千haを超え、その後においても高級かぶせ茶の生産技術、被覆茶園の阻害要因の解明と回避技術などの試験研究が継続され、平成6年(1994)らは全国茶品評会において連続農林水産大臣賞を獲得するなど、名実共に日本一のかぶせ茶産地となった。

・摘採作業の省力化に係る試験研究<br>
　手摘み (大正初期まで) ~挟摘み (昭和30年初期まで) を経て、 昭和35年(1960)ころから動力摘採機(バッテリー式回転刃又は動力バリカン式)が開発され、その使用法と効率に係る試験が行われると共に機械に合わせた整枝、樹型の試験が行われた。

　昭和45年(1970) 頃から可搬式摘採機の普及に伴い作業効率と茶園畝の関係が検討され、 平成7年(1995)には、乗用型摘採機が本県に導入され、 茶園畝の長さと作業効率、既存茶園の機械効率利用、 土壌鎮圧と土壌物理性の改善などの試験が行われ、 大型茶園管理機械の体系化の研究が進むと共に、 平成16年(2004)には県下の乗用型摘採機は200台に達し、 労働力不足解消と大規模企業的茶業経営の実現に大きく寄与した。

　一方、茶園管理の機械化と併せて、中山間傾斜茶園での機械利用から中山間傾斜茶園のテラス式整備法と省力、 軽作業化技術の開発試験が行われている。

・防霜技術の開発に係る試験研究<br>
　元来、 茶生産における晩霜害は一番茶を全滅に至らしめる気象災害で、 この防除には早くから種々の試験研究が行われているものの、昭和45年(1970) の防霜ファン開発やスプリンクラー利用技術の開発までは、こもかけ、 煙幕発生などの方法など限られたもので、 防霜効果も限定的なものであった。

　昭和45年(1970)、 本県茶業分場研究員の横山俊祐によって開発された防霜ファンは、地上7~10m付近に形成される暖かい空気の層 (逆転層) をファンで茶園面に降下させる理論で、全国的に注目され、 各試験研究機関や電気メーカも挙って参加した中で、 昭和46年(1971)~56年(1981)に亘って現地試験を重ね、 ファンの設置位置、 角度と効果などを実証した。 この効果は画期的なもので、 この防霜ファン開発によって茶生産は飛躍的に安定した。

　なお、この防霜技術は平成6年 (1994) の日本農業研究百周年記念事業において、最も顕著な技術として茶業研究において唯一表彰された。その他、スプリンクラー多目的利用技術において、灌水による防霜技術確立の試験研究は昭和45年(1970) から試みられているが、国及び他府県の試験研究結果において有効な技術として確立されている。

### (3) 病害虫に関する試験研究

　戦前の茶病虫害防除は主に石灰硫黄剤、 徐虫菊乳剤など天然系農薬を使用した防除や耕種的手法による防除が主体であったが、昭和30年(1955) 頃からは化学農薬が続々出現し、 病害虫防除に関する試験研究は化学農薬が主体となった。また、昭和36年(1961)からは害虫発生予察による防除時期判定の試験が行われると共に病害虫防除の省力化に関する試験が行われている。

　化学農薬主体の防除法は昭和50年(1975) 頃まで続いたが、この頃から化学農薬多用における残留や生態系破壊の懸念が問題となり、従来の耕種的手法による防除法の見直しと併せて天敵利用など、 減農薬による環境にやさしい防除法の確立が試験研究の大きなテーマとなった。

　特に本県では、 茶樹の主要害虫であるハダニ類、 ハマキムシ類の化学農薬に代わる防除法として、 合成ピレスロイド系薬剤のハダニ類に対する防除効果試験、 カンザワハダニの天敵ケナガカブリダニの放飼試験、 昆虫特有の性フェロモンを利用したハマキムシ類の交信かく乱やフェロモントラップへの雄虫誘殺と発生予察への応用など、天敵と生物的農薬資材、 更には耕種的手法を組合わせた総合的減化学農薬の防除体系の確立に関する試験研究は全国の先端を行く試験研究として注目に値する。

### (4) 製造に関する試験研究

　本県の製造に関する試験研究は、 昭和34年(1959)、 国において紅茶振興計画が樹立され、これに基づき本県も同35年(1960) に 「三重県紅茶振興計画」を樹立し県挙げて紅茶振興策を講じたことから、 この頃は試験研究の主体は紅茶に置かれていた。

・紅茶に係る試験研究<br>
　太平洋戦争で一時中断されていたが、 昭和23年 (1948)、 本県鈴鹿郡野登村の川戸勉らが紅茶生産に着手し、 また、 戦後の食生活の洋風化で紅茶生産の機運が高まっていたこともあって、県も紅茶生産に期待をかけていた時期でもあった。紅茶製造試験は昭和28年(1953) から再開し、 各種試験が行われたが、 昭和46年(1971)に紅茶の完全自由化が実施されることで紅茶園は緑茶園へ政策転換が図られ、 紅茶の試験研究は昭和42年(1967) をもって中止された。

・緑茶製造に係る試験研究<br>
　製茶の機械化が進むにつれて其々の製茶機械の性能及び使用試験が行われ、 また、機械燃料として従来の木炭、 薪からプロパンガス、石油ガス、ブタンガスなど使用試験が昭和29年(1954)~40年(1955) において行われている。
　また、製茶機械の大型化と共同製茶が進んだ昭和50年(1975) 代には、各機械の風量や熱量と製茶品質の関係や合葉製造に係る生葉の格付、 製茶冷蔵保存に関する試験などが行われ、一方、北勢地方のかぶせ茶生産の増加に対応するため、かぶせ茶製造法の試験が行われた。

　昭和62年（1987）〜平成2年（1990）には、新製品開発の一環として半発酵茶「新香味茶」の開発を目指し、「み〜ろん」として商標登録された。

　平成8年（1996）頃からは、茶の機能性（効能）が認識されると、茶の消費形態も多様化し、食べるお茶や菓子の原料としての茶の需要が高まり、これに併せて茶のクリーン化製法が試験研究テーマとなり、製茶工程並びに製品における細菌数調査と減菌法など安全管理に関する試験研究が行われる一方、茶の機能性に注目した抗アレルギー物質を含有した茶の開発に係る試験研究が行われている。

## 7．三重県茶業試験所講習生（大正15年（1926）4月〜昭和40年（1965）までの記録）

### （1）茶業講習制度の沿革
<dl style="margin: 0 0 0 2rem">
<dt style="font-weight: normal;">大正15年4月（1926）</dt>
<dd>三重県茶業試験所（三重県茶業組合聯合会議所管）が、三重県（内務部農商課主管）移管と同時に、三重県告示第153号を以って三重県茶業試験所講習生規程を設定し茶業講習生制度が発足した。</dd>
<dt style="font-weight: normal;">昭和12年4月（1937）
<dd>三重県茶業試験所の鈴鹿郡亀山町移転に伴い、先の規程を廃止し、新たに三重県茶業試験場講習生規程が設定された。</dd>
</dl>

（2）講習事業の内容
<dl style="margin: 0 0 0 2rem">
<dt style="margin: 0; font-weight: normal;">①目的</dt>
<dd>将来茶業の指導者又は茶業に従事しょうとする者に対し、茶の関する必要な学理及び技術を習得せしめるため講習を行なう。
<dt style="margin: 0; font-weight: normal;">②講習の種類
<dd>イ、長期講習生　（新制高等学校）を卒業した男、又は、これと同等以上の学力を有し、茶業の実務に経験のある18歳以上の男子<br>
ロ、短期講習生　（新制中学校）を卒業した男、又は、これと同等以上の学力を有する15歳以上の男子<br>
ハ、臨時講習生 茶業の実務に経験のある15歳以上の男子
<dt style="margin: 0; font-weight: normal;">③ 講習期間</dt>
<dd>長期講習生　1ヶ年 (4月1日から翌年3月31日)<br>
短期講習生　5ヶ月 (5月1日から同年9月30日)<br>
臨時講習生　一番茶開始から三番茶終了迄</dd>
<dt style="margin: 0; font-weight: normal;">④ 講習科目</dt>
<dd>長期・短期講習科目<br>
　(イ) 学科科目 茶業汎論 茶業経営論、 茶樹栽培論、製茶論
　(口) 実習科目茶製造、製茶審查、茶再製加工、茶樹栽培、病害虫防除、苗木増殖及び栽培<br>
臨時講習科目<br>
　(イ) 学科科目 製茶論<br>
　(口) 実習科目 製茶及び製茶審査</df>
<dt style="margin: 0; font-weight: normal;">⑤ 講習施設</dt>
<dd>講習の施設はすべて、 茶業試験所のものを使用する。</df>
