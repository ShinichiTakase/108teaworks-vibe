# 注文明細スナップショット（microCMS order_snapshots）の設定

注文確定時に送ったメール本文を保存し、発送完了メール送信時に「注文番号＋注文者メール」で照合して本文に含めるために使います。

## 1. microCMS で API を追加

1. [microCMS ダッシュボード](https://108teaworks.microcms.io/) にログインし、**API を新規作成** する。
2. **API 名**: `order_snapshots`（API ID も `order_snapshots` のままにする）。
3. **フィールド** を次のとおり追加する。

| フィールドID | 種類     | 必須 | 説明 |
|-------------|----------|------|------|
| orderNo     | テキスト | あり | 注文番号（R-で始まる番号） |
| email       | テキスト | あり | 注文者のメールアドレス |
| body        | テキスト | あり | 長文。注文確認メールの HTML 本文をそのまま保存 |

- **body** は「複数行テキスト」または「リッチエディタ」ではなく、**テキスト（長文可）** にし、HTML が 1 本の文字列として入るようにする。
- 一覧で検索しやすいように、**orderNo** と **email** にインデックスや検索設定があれば有効にしておく（任意）。

## 2. API キー

- **読み取り**: 既存の `MICROCMS_API_KEY` で OK（発送完了メール送信時に参照する）。
- **書き込み**: 注文確定時に保存するため、この API に対する **書き込み用 API キー** を発行し、`.env.local` の `MICROCMS_WRITE_API_KEY` に設定する。  
  （書き込み用キーを別にせず、既存の API キーに書き込み権限を付与している場合は、`MICROCMS_API_KEY` のみでも動作します。）

## 3. 動作の流れ

1. **注文確定時**（`/api/checkout/complete`）  
   お客様へ送った「ご注文の確認」メールの HTML 本文を、  
   `orderNo` と `email` と一緒に **order_snapshots** に 1 件保存する。

2. **発送完了メール送信時**（`/admin/send-shipping`）  
   入力された「注文番号」と「送信先メールアドレス」で **order_snapshots** を検索する。  
   ヒットした場合、保存してあるメール本文を「お届けしたご注文内容」として発送完了メールに埋め込む。  
   ヒットしない場合は、これまでどおり注文番号・追跡番号のみの本文で送信する。

## 4. 注意

- **既存の注文**（この機能を入れる前に確定した注文）は order_snapshots にないため、発送完了メールには注文明細は出ません。手動で送る場合は従来どおりの内容になります。
- **body** には HTML が入るため、microCMS の「テキスト」で長文が扱えることを確認してください（多くのプランで問題ありません）。
