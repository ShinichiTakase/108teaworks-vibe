# 発送完了メールの送信

注文品を発送したあと、お客様に「発送しました」と通知するメールを送る機能です。

## 使い方

1. **環境変数を設定する**  
   `.env.local` に以下を追加し、任意の長い文字列（認証キー）を設定します。
   ```env
   ADMIN_SHIPPING_SECRET=あなたの秘密の文字列
   ```
   ※ 既存の SMTP（Brevo 等）の設定がそのまま使われます。

2. **発送したら送信する**  
   ブラウザで次のURLを開きます（本番サイトで実施してください）。
   ```
   https://108teaworks.com/admin/send-shipping
   ```
   - **認証キー**: 上で設定した `ADMIN_SHIPPING_SECRET` の値を入力
   - **送信先メールアドレス**: 注文者に届いた「ご注文の確認」メールの送信元＝お客様のメールアドレス
   - **注文番号**: 注文確定メールに記載の「注文番号」（R-で始まる番号）※必須
   - **お問い合わせ番号・追跡番号**（任意）: 宅配業者の追跡番号など

   「発送完了メールを送信」を押すと、そのアドレスに発送完了メールが1通送信されます。

3. **注文明細をメールに含める場合**  
   注文確定時に送ったメール本文は、サーバーの **ファイル**（`ORDER_SNAPSHOTS_DIR`）に保存されています。  
   **注文番号** と **送信先メールアドレス** を入力して送信すると、保存済みの注文内容を「お届けしたご注文内容」として発送完了メールに自動で含めます。  
   （設定は `docs/ORDER-SNAPSHOTS-SETUP.md` を参照。Vercel ではファイルが永続しないため、自前サーバー等で利用。）

## 注意

- `/admin/send-shipping` は検索エンジンにインデックスされないよう `noindex` にしています。
- 認証キーは他人に知られないようにし、本番では必ず `ADMIN_SHIPPING_SECRET` を設定してください。
- 送信には既存の注文確認メールと同じ SMTP（ORDER_FROM / CLIENT_MAIL_FROM 等）を使います。
